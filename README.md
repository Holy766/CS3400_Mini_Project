# CS3400_Mini_Project
A C++ Library Management System that manages the library's resources and the people using them, with each data structure chosen for a specific job.


# Project structure
```text
CS3400_Mini_Project/
├── main.cpp
├── include/        # .h files
├── src/            # .cpp files
├── data/           # resources.txt, requests.txt, locations.txt
├── docs/           # report drafts, diagrams
├── tests/          # test inputs and expected outputs
├── Makefile
├── README.md
└── .gitignore
```
